Dependabot can produce a flood of pull requests. Merging multiple PRs can be problematic, so group all PRs in to a single PR.

1. Copy the following:

version: 2

updates:
  - package-ecosystem: "github-actions" # search for actions - there are other options available
    directory: "/" # search in .github/workflows under root `/`
    schedule:
      interval: "weekly" # check for action update every week
    open-pull-requests-limit: 10
    groups:
      actions-deps:
        patterns:
          - "*"

1. and save as dependabot.yml at /.github/depdendabot.yml

1. Open the pull request tab and find a single, grouped PRs, and scroll to the bottom to find that "No conflicts with base branch; Merging can be performed automatically."

To merge using CLI:

Step 1 Clone the repository or update your local repository with the latest changes.

git pull origin main

or 

git fetch origin main

Step 2 Switch to the base branch of the pull request.

git checkout main

Step 3 Merge the head branch into the base branch.

git merge dependabot/github_actions/actions-deps-58ca332302

or 

git merge origin/dependabot/github_actions/actions-deps-58ca332302

This gives

Updating 2b16af6..8826e93
Fast-forward
 .github/workflows/publish.yml | 4 ++--
 1 file changed, 2 insertions(+), 2 deletions(-)

Step 4 Push the changes.

git push -u origin main
